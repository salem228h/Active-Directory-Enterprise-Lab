# Project Overview

## Introduction

This project demonstrates the deployment of a complete Microsoft Active Directory enterprise infrastructure using Windows Server 2022 and Windows 11 Enterprise.

The objective was to build a realistic enterprise lab that simulates the daily responsibilities of an IT Support Specialist or Junior System Administrator. The environment includes centralized identity management, DNS, DHCP, Group Policy, File Services, and domain-joined client management.

---

## Business Scenario

Northwind Technologies is a growing company that recently expanded its workforce and requires a centralized IT infrastructure.

The company needs:

- Centralized authentication
- Centralized user management
- Secure file sharing
- Centralized policy management
- Automatic IP address assignment
- Enterprise DNS services

To meet these requirements, Windows Server 2022 was deployed as the organization's first Domain Controller.

---

## Objectives

- Deploy Windows Server 2022
- Configure Static Networking
- Install Active Directory Domain Services
- Deploy DNS
- Deploy DHCP
- Create Organizational Units
- Create Domain Users
- Create Security Groups
- Join Windows 11 Enterprise to the Domain
- Configure Group Policy
- Deploy File Server
- Configure NTFS Permissions
